# Quant Alpha Research

Open-source quantitative research project for exploring alpha generation and backtesting workflows.

## Objective

Build reproducible research pipelines for testing quantitative strategies.

## Features

- Research workflow
- Signal experimentation
- Backtesting

## Tech Stack

- Python
- Pandas
- NumPy

## Run

Install:

pip install -r requirements.txt

Execute:

python main.py
